# Todora

A 2.5D top-down racer in [Rust](https://www.rust-lang.org/) and [Bevy](https://bevy.org/). Right now it is a car on a plane.

```sh
cargo run
```

**WASD** or **arrows** to drive. **Shift** to brake.

Needs a recent stable Rust (`rustup` on macOS). First Bevy compile is slow; later ones are not.
